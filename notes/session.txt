api/session → "Am I logged in? What roles?"

1. check with valid token
  curl -H "Authorization: Bearer TOKEN" \
  http://192.168.0.104:8086/api/session

On success return eg: {"authenticated":true,"userId":"349847527111000068","roles":["admin"],"isAdmin":true,"isUser":false}% 

2. check with Wrong token or no token
  curl -H "Authorization: Bearer WRONGTOKEN" \
  http://192.168.0.104:8086/api/session

  Expected output: {"authenticated":false,"roles":["anon"]}%
